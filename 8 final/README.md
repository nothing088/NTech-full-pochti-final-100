# NOTHING TECH

Telegram-магазин на Render + Docker + MongoDB.

Изменения:
- бренд переименован в NOTHING TECH;
- логотип используется в интерфейсе и во всех исходящих сообщениях бота;
- карточка товара поддерживает динамические характеристики (цвет, память и любые другие) с вариантами, собственной ценой и остатком;
- в товаре поддерживаются несколько внутренних вкладок с описаниями;
- характеристики и вкладки редактируются из админки;
- исправлено удаление способов доставки/самовывоза;
- добавлен профиль аккаунта со статистикой заказов, активных заказов и суммы покупок;
- сохранены Render, MongoDB, YooKassa, товары, категории, корзина, заказы, доставка, промокоды, поддержка и FAQ.

## Deploy
Сохраните Environment Variables Render из `render.yaml`, особенно `BOT_TOKEN`, `MONGODB_URI`, `MINI_APP_URL`, `PUBLIC_BASE_URL` и `ADMIN_SECRET`, затем выполните deploy.
